## Proyecto destacado

### Seguridad Vial en Bogotá — Analítica end-to-end (SQL + Python + Power BI)

Pipeline completo sobre **199.146 siniestros viales** de Bogotá (datos abiertos
2015–2021): descarga, ETL, modelo estrella, KPIs y tablero interactivo en Power
BI.

- **Hallazgo clave:** el volumen de siniestros y el riesgo por habitante **no
  coinciden**; prioricé localidades con un índice de doble criterio (volumen +
  tasa por 100.000 hab.).
- **Alcance:** SQL, Python (pandas), SQLite, Power BI/DAX y documentación.
